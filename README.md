# ジェットコースターをつくろう

パーツをつないで自分のコースを作り、実際にコースターを走らせられるWebアプリです。
小学校の理科（位置エネルギー・運動エネルギー）の教材として使えます。

**▶ アプリを開く: https://daiki0807.github.io/jet-coaster/**

## できること

- **パーツを選んでコースづくり** — まっすぐ／上り／下り／まきあげ／カーブ／Uターン／ループ／こぶ／ひねり／コークスクリューなど15種類をクリックで継ぎ足し
- **スタートへ自動接続** — 自分で作った部分はそのままに、「スタートにつなぐ」で安全な帰り道だけを自動作成。左右の別経路、つなぎ直し、一括取り消しにも対応
- **細かい調整** — 置いたパーツを選ぶと、長さ・上り下り・まがり・かたむき・ひねりをスライダーで変更できる
- **迷いにくいカメラ** — カーソル／2本指の中央を保ったズーム、視点の平行移動、「スタート」「ゴール」「全体」への移動に対応
- **視点の切り替え** — 走行中に「三人称」「一人称」を切り替え（キーボードの `V` でも可）
- **早送り・まきもどし** — 走行中に「ふつう／×2／×4」で早送り（時間のかかる巻き上げをさっと飛ばせます）。「⏪ まきもどし」で走ったところを逆再生。ゴールしたあとでも戻して見返せます
- **音** — 巻き上げのチェーン音、レールのつなぎ目の音、風を切る音、ブレーキ音がスピードに合わせて変化。ワンタップで消音できます
- **本物の物理** — 高さが足りないとループの途中で失速して戻ってくる。スピード・高さ・Gフォース・「ふわっと時間」をリアルタイム表示
- **スリル点数とミッション** — ゴールすると、はやさ・ふわっと・ドキドキ・ながさの内訳つきで点数と★ランクが出ます。「ふわっと1.5秒」「4Gをこえずにゴール」など6つのミッションつき（クリアはブラウザに記録）
- **ふわっとしたらバンザイ** — Gが0.3を下回ると、乗っている人が手をあげます
- **保存とおてほん** — 作ったコースをブラウザに保存／よみこみ。おてほんコース4種つき

## 操作

| そうさ | やり方 |
|---|---|
| コースを回して見る | 画面をドラッグ |
| 見る場所を移動 | 右ドラッグ（スマホは2本指で移動） |
| ズーム | マウスホイール（スマホは2本指で拡大・縮小） |
| 場所を見つけ直す | 画面上の「スタート」「ゴール」「全体」 |
| 走らせる／止める | `スペース` キー |
| 早送り／まきもどし | 走行中の「⏪ まきもどし ／ ▶ ふつう ／ ⏩ ×2 ／ ⏩⏩ ×4」ボタン（`←` `→` キーでも切り替え） |
| 視点の切り替え | `V` キー |
| 音のオン・オフ | `M` キー |

## 教材として使うときのポイント

- はじめの高さより高い山は越えられません（エネルギー保存）。「なぜ登れないのか」を考える場面に使えます
- Gフォースの表示は符号つきです。丘の頂上では0以下（青字＝ふわっと浮く）、ループの底では大きな正の値（赤字）になります
- 失速したときは「スタートを高くする」「まきあげを長くする」「ループを小さくする」という手がかりが画面に出ます
- 「ふわっと時間」はGが0.3を下回っていた時間の合計です。こぶの頂上やループの上で増えるので、「どこで体がふわっとするのか」を数値で確かめられます
- 点数は 6G をこえると「こわすぎ」で減点されます。実際のコースターの安全基準（およそ5〜6G）を話す入り口に使えます
- ミッションの「まきあげなしでゴール」は、スタートの高さだけでゴールまで到達させる課題です。位置エネルギーだけで走らせる実験になります
- 早送りをしても物理計算はそのまま（計算のきざみを細かく保ったまま回数を増やしています）。まきもどしは走った記録をたどる逆再生なので、そこから「ふつう」に戻せば同じ続きを何度でも観察できます

## 技術メモ

- 外部ライブラリ・ネット接続なしの **HTML1ファイル完結**。ダウンロードしてダブルクリックするだけでも動きます
- 起動時は空のコースです。おてほんコースは必要なときだけ選んで読み込めます
- 3D描画は自作のWebGL（Three.js等は不使用）
- 音は Web Audio API でその場で合成（音声ファイルは持っていません）。ブラウザの制限に合わせ、「走らせる」を押した時点で音の準備をします
- コースは「進路（向き）」と「かたむき（バンク）」を分離して計算しているため、らせんカーブでもコースがねじれません
